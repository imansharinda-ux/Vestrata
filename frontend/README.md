# Vestrata Frontend

React + Vite frontend for Vestrata.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Structure

```
src/
  components/   UI sections and reusable pieces
  data/         Static content (links, features, steps, reviews)
  styles/       base, animations, components, sections
public/
  images/       Photos
  fonts/        Inter font files
```
